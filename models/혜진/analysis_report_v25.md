# v25 — X와 *를 같은 표기로 학습한 재학습 모델

## 이전 v24와 차이

v24는 저장된 v23 모델을 재사용하고 예측 입력만 통일했습니다. v25는 사용자의 명시적 요구에 따라 **기존 학습 모델 파일을 로드하지 않고 모든 구성 모델의 변수 선별·스케일러·분류기 fitting을 다시 수행**했습니다. 파라미터를 새로 탐색하지 않고 v23 고정 구조와 비중(base 60%, 증강 OVA 20%, 증강 MLP 20%)을 유지했습니다. 참고 후보 설정을 정의하는 코드가 포함되지만, 후보 전부를 탐색하지 않습니다.

## 동일 표기 처리

표준 한 글자 아미노산 + 양의 위치 + 끝 X인 토큰을 *로 통일합니다. 학습 입력에 *와 X가 섞인 합성 표기를 먼저 만들고, 학습 전 정규화가 원본 train과 정확히 같은 입력을 만드는지 확인했습니다. 실제 fit은 정규화된 입력으로 수행했습니다. parser의 token key, 효과 분류 및 중복 판단에도 정규화가 적용됩니다. 예측에도 같은 정규화를 적용합니다. 별도 가중치 재사용 버전이 아닙니다.

`R1450X`, `R1450*`, `p.R1450X`, `p.R1450*`는 같은 종결 효과로 처리합니다. X가 참조 아미노산인 경우나 삽입·범위·frameshift 문구는 일괄 치환하지 않습니다. parser의 불확실성 괄호는 해당 불확실성 플래그를 보존합니다. canonical_frame은 표준 독립 토큰만 치환하며, 모든 가능한 HGVS 표기 전체의 동치를 보장하는 완전한 HGVS 구현은 아닙니다.

## 그룹 검증 결과

train 6,201명 중 기존 개발 집합 4,960명에 대해 seed23033 3-fold 그룹 검증을 새로 수행했습니다. 각 fold는 학습 부분에서만 변수 선별·DF·스케일러·모델을 fit했습니다. 동일하거나 정규화된 프로필이 같은 그룹에 있으며 과거 홀드아웃은 평가하지 않았습니다. 기존에 반복 사용한 개발 환자들이므로 독립 외부 환자 검증은 아닙니다.

이 모델은 표기 호환성을 목적으로 한 재학습 실험입니다. v23보다 개선되었다는 통계적 채택 주장은 하지 않습니다. train에 대상 X 원문이 없고 정규화 후 입력은 동일하므로 재학습 자체가 점수 상승을 보장하지 않습니다. 데이터 내용이 같은 두 표기에 대한 일관성이 목표입니다. 실제 대회/Public 점수는 미확인입니다.

## 전체 학습·저장·추론

검증 종료 후 train 전체 6,201명으로 모든 구성 모델을 다시 fit하고 저장했습니다. `artifacts/v25/cancer_model_v25_legacy_stop_retrained.pkl`에는 학습된 전체 앙상블, parser 및 입력 정규화 함수가 포함되어 있습니다. 외부 프로젝트 Python 파일 없이 cloudpickle로 로드하고 `model.predict_frame(frame)`을 호출합니다. 입력은 `model.genes_` 유전자 열이고 출력 확률의 암종 순서는 `model.classes_`입니다. 저장 후 재로딩 동치와 배치 순서 독립성도 확인했습니다.

`cencer_v25.ipynb` 하나에 선별·그룹 검증·재학습·저장·최종 제출 생성 코드가 모두 들어 있습니다. 파이썬 파일은 제출할 필요가 없습니다. 처음부터 재현할 때 data/train.csv가 필요하며, 최종 추론에 data/test.csv와 sample_submission.csv가 필요합니다.

## 누수·설계 출처와 가정

모델 fitting, 선별, CV 과정의 test/sample 접근을 audit hook으로 차단했습니다. test는 고정 모델의 마지막 제출 추론에서만 읽었습니다. 다만 legacy-X 해석은 test 표기 차이를 이미 확인한 뒤 도입한 가정이므로 설계 자체가 test와 무관하다고 주장하지 않습니다. test의 정답이나 모델 학습용 샘플·라벨을 사용하지 않았습니다. X가 실제로 옛 종결이라는 데이터 생성 규약은 미확인입니다.

- [HGVS 공식 표기 변경 이력](https://archive.hgvs-nomenclature.org/versioning/)
- [현재 HGVS에서 X의 의미](https://hgvs-nomenclature.org/main/recommendations/uncertain/)

## v24와 최종 제출의 관계

v25는 실제로 모든 구성 모델을 재학습했지만, 이번 제출 CSV는 v24와 바이트 단위로 동일했습니다. train에 대상 X 표기가 없어 두 버전의 정규화된 학습 입력이 같고 구조·난수를 유지한 결과입니다. 파일만 복사하거나 모델을 재사용한 것이 아닙니다. 따라서 v24와 다른 제출 결과나 추가 점수 향상을 기대할 근거로 제시하지 않습니다. v25의 추가 산출물은 실제 재학습과 그룹 검증 환자에서의 세 표기 동치 확인입니다.
