# v27 — Geneformer V2 고정 임베딩과 치환 proxy의 효과 분리

## 목적과 출처

사용자가 제공한 민준 `v11_clean.ipynb`의 FeatureBuilder와 Geneformer embedding 아이디어를 참고했습니다. 팀원 전달 Public 0.4474568058, 문서 CV 0.4972는 이 실험의 재현 점수로 주장하지 않습니다. 팀원 제출에는 형제 라벨 후처리가 포함되지만 이번 실험에는 넣지 않았습니다.

v26의 경로·동반 변이+XGB/LR 구조 대신 **LightGBM+로지스틱 회귀**의 단순한 구조에서 네 설정을 비교했습니다. base는 변이 유전자·절단형 유전자·위치 핫스팟 및 환자별 개수/비율입니다. Geneformer는 LR에만 추가하고 치환 proxy는 두 모델 모두에 추가했습니다. 주 후보는 결과 전에 both로 고정했습니다. 다른 ablation이 좋더라도 outer 결과로 주 후보를 바꾸지 않았습니다.

## Geneformer 사용 방식과 재현

- 공식 저장소: `ctheodoris/Geneformer`, 리비전 `1f7fbae4e469a5f4f1af8c111a529cfe1b3829f5`.
- 모델: Geneformer-V2-104M, Apache-2.0 표기 확인.
- 사용한 텐서: `bert.embeddings.word_embeddings.weight`, 원본 크기 [20275, 768].
- 연결: 4,384개 유전자 중 **4377개(99.8403%)**, 연결되지 않은 7개는 영벡터.
- silent 이외로 분류된 변이가 있는 유전자들의 768차원 벡터를 평균·최댓값으로 요약해 **1,536개 변수**를 LR에 추가했습니다. 단백질 변이의 alt 자체를 Geneformer 토큰으로 넣은 것이 아닙니다.
- Transformer attention forward나 fine-tuning은 하지 않았습니다. 원래 유전자 발현용 사전학습 표현을 변이 유전자 집합에 응용한 방법이며, 원 논문의 전체 추론 방식을 재현한 것이 아닙니다.
- 유전자 매핑과 원본 가중치 checksum, 추출한 float32 표 checksum을 manifest에 기록했습니다. 사전은 임의 클래스 복원을 허용하지 않는 restricted unpickler로 읽고, safetensors에서 F32 embedding만 추출했습니다.
- 새 환자 추론에 필요한 표와 정규화/모델은 최종 피클에 포함되어 원본 398MiB checkpoint나 외부 Python 파일 없이 추론 가능합니다.
- 노트북을 처음부터 실행할 때 추출 표가 없으면 고정 리비전의 파일을 내려받고 체크섬을 검증합니다. 최초 재현에는 네트워크가 필요합니다.

[공식 Geneformer 모델 카드](https://huggingface.co/ctheodoris/Geneformer)에 따르면 V2 기본 모델은 비암 단일세포 발현 자료로 사전학습됐습니다. 경쟁 데이터로 추가 사전학습하지 않았으며 외부 환자 테이블을 합치지 않았습니다. 사전학습 환자와 대회 환자의 개별 신원 중복을 독립적으로 감사한 것은 아니므로 완전한 무중복을 입증했다고 주장하지 않습니다. 외부 사전학습 지식을 사용했다는 출처를 명시합니다.

## 아미노산 기반 치환 proxy

표준 64개 코돈에서 한 염기만 바꿔 refAA→altAA가 되는 가능한 경우를 열거했습니다. 이를 C>A, C>G, C>T, T>A, T>C, T>G 여섯 범주로 접고 가능한 코돈 경로에 균등 비중을 주어 환자별 비율을 계산했습니다. 유전 암호표의 ATG/M, TGA/stop, AAA/K 및 각 벡터 합 1을 확인했습니다.

이 데이터에는 실제 DNA 코돈과 삼염기 문맥이 없으므로 **실측 SBS6/SBS96나 특정 암 유발 과정의 노출량이 아닙니다.** 균등 코돈 가정에 기반한 공학적 요약 변수입니다. UV·흡연·APOBEC 원인을 환자별로 판정하지 않습니다. 아미노산 조성의 효과와 실제 돌연변이 과정의 효과를 구분해 입증한 것도 아닙니다. 보존적인 v25 parser로 해석 가능한 이벤트만 사용하고 모호하거나 복잡한 이벤트는 억지로 단일염기 치환으로 해석하지 않았습니다.

팀원 피처 이름의 `inframe`은 여기서도 삽입/삭제 등 표기의 거친 묶음으로만 사용하며, DNA reading frame이 실제 보존됐다고 판정한 것이 아닙니다.

## 학습·선별·검증

- 개발 4,960명에 대해 v25/v26과 동일한 seed23033 그룹 3-fold. 동일 raw/정규화 프로필은 같은 그룹으로 묶었고 과거 홀드아웃 1,241명은 평가하지 않았습니다.
- train SHA256 및 fold별 학습/검증 인덱스 fingerprint를 검사했습니다. v25 비교값은 동일 분할의 문서화된 점수이며 새로운 baseline 재학습으로 표시하지 않습니다.
- 유전자 DF>=5, 절단형 유전자 DF>=3, 위치 핫스팟 DF>=3은 각 학습 부분에서만 정했습니다. LR의 MaxAbsScaler도 각 학습 부분만 사용했습니다.
- LGB leaves15·lr0.05·feature_fraction0.3, 최대3000/early stop100. outer 학습 부분 안에서 그룹 5-fold의 한 fold로 종료 회수를 고른 뒤, outer train 전체에 어휘와 모델을 다시 fit했습니다. inner 어휘도 inner train에서만 fit했습니다.
- LR C=0.1, balanced, max_iter1000. LGB/LR 비중은 0.5/0.5 고정. Geneformer의 촘촘한 변수를 LGB의 컬럼 샘플링에 섞지 않았습니다.
- 동일 SIG 설정의 LGB를 GF ON/OFF에서 공유해 불필요한 재학습만 줄였습니다. 공유 범위는 동일 학습 fold 안이며 검증/다른 fold로 모델을 넘기지 않았습니다.
- base/GF/proxy/both의 네 가지를 기록했고, OOF 비중 최적화·형제 라벨 반전·COAD prior는 사용하지 않았습니다.

## 저장·산출물

결과 전에 지정한 both 모델을 실험용 전체 train 모델로 학습했습니다. 최종 tree 변수 **9345개**, LR 변수 **10881개**, tree 회수 **98**입니다. 기준 미달이어도 버전 재현을 위해 저장하되 새 최고 모델로 자동 추천하지 않습니다.

- `cencer_v27.ipynb`: 전처리·가중치 취득/검증·변수 생성·그룹 CV·전체 학습·저장·최종 추론 포함.
- `artifacts/v27/cancer_model_v27_geneformer_proxy_experimental.pkl`: 추론 입력은 genes_ 열, 출력 확률 순서는 classes_.
- `artifacts/v27/pretrained/manifest.json`: 공식 리비전·원본 파일 및 추출 표 checksum.
- `artifacts/v27/selected_variables.csv`: LR 전체 변수명. tree는 GF를 뺀 부분입니다.
- `submission/혜진_submission_v27_geneformer_proxy_experimental.csv`: 고정 모델의 최종 예측.
- `requirements-v27.txt`: 실행 환경.

각 fold 12명의 현재/X 합성 표기 예측 동치, 저장 후 재로딩, 별도 추론 프로세스의 배치 순서·ID·확률·2,546행을 확인했습니다. v25에서 보완한 표기 정규화 가정은 과거 test 표기를 관찰한 뒤 도입됐으므로 설계 자체가 test와 무관하다고 주장하지 않습니다. 이번 GF/proxy 학습·선별·CV는 test/sample 접근을 audit hook으로 차단했고, 마지막 고정 모델 추론에서만 읽었습니다. 원본 데이터와 기존 버전은 보존했고 Public은 미확인입니다.
