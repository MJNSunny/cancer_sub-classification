# v17 — 기존 앙상블과 문헌 기반 변이 표현의 결합

## 목적과 이번에 달라진 점

v16은 단순 모델 전처리 대조여서 v10 앙상블과 직접 비교할 수 없었습니다. v17은 같은 학습/평가 그룹 안에서 기존 v10을 재학습해 비교합니다. 기존 로직의 v6 75% + 유형 ComplementNB(alpha 0.1) 25%를 기준으로 고정했습니다. 기존 후보 설정을 출력하지만 과거 59개·24개 후보 탐색은 반복하지 않습니다.

새 모델은 v16의 `rare_backoff` 표현, min_df=3, chi2 최대 8,192열, 학습 MaxAbs와 exact DF 감쇠를 사용합니다. LR C=1은 v16 C=0.1 대비 정규화 강도를 완화한 고정 가설이며 LightGBM은 300회·15 leaves·depth 5·lambda 10·min_child 20으로 제한했습니다. 전체 환자에 동일한 혼합 비율을 적용하고 클래스별 비율·예측 개수를 조정하지 않습니다. 특징 수를 늘렸다는 사실 자체가 개선 근거는 아닙니다.

논문 근거와 입력 한계는 [v16 문헌 보고서](LITERATURE_REVIEW_AND_PREPROCESSING_V16.md)를 따릅니다. 새로운 외부 환자·정답은 추가하지 않았고 DNA signature·기능 점수는 만들지 않았습니다. 파생변수의 상세 의미도 해당 문서와 동일합니다.

이번 비교는 파서·표현·선택 열 수·LR 규제·추가 알고리즘을 묶어 평가한 것입니다. 성능 차이를 어느 한 변경의 인과효과로 분해한 실험은 아닙니다.

## 사전 고정 검증

- train 6,201명에서 기존 홀드아웃을 보존하고 개발 4,960명만 검증했습니다.
- raw 동일 및 고정 파서로 정규화한 동일 프로파일을 union group으로 묶었습니다. 홀드아웃과 충돌하는 개발 환자는 제외합니다.
- outer StratifiedGroupKFold 3-fold seed 17017, inner 2-fold seed 17018+outer fold입니다.
- 어휘·학습 DF·스케일·선택 변수·모델·증강 분포는 해당 학습 fold에서만 적합했습니다. 증강은 학습 환자에만 추가했습니다.
- 후보는 기준 v10 단독, v10 80%+새 LR 20%, v10 80%+새 LGB 20%, v10 60%+LR 20%+LGB 20% 네 개입니다. inner 평균 Macro F1로 선택한 뒤 outer에서 한 번 평가합니다.
- 기준 모델 선택 동률은 기준 우선입니다. 최종 저장 조합은 inner 선택 다수결, 동률 시 inner 평균으로 정합니다. outer 최고 조합을 최종 성능으로 쓰지 않습니다.
- 사전 채택 기준: nested-v10 평균 +0.003 이상, 모든 outer fold 비하락. 조건 미달이면 실험용으로만 보관합니다.
- test/sample 접근은 실행 단계에서 차단했습니다. 기존 홀드아웃 재평가·제출 CSV 생성·기존 모델 교체는 하지 않았습니다.

## 파일과 재현

`cencer_v17.ipynb` 하나에 기존 앙상블·새 파서·새 모델·중첩 검증·선택·최종 저장·이 보고서 생성을 포함합니다. `requirements-v17.txt`와 공식 `data/train.csv`가 필요합니다. 학습 fold ID, train SHA256와 프로토콜이 일치하는 train-only 캐시만 재사용하며 캐시가 없으면 다시 학습합니다. 프로젝트 .py 파일이나 test는 실행 의존성이 아닙니다.

모델 저장: **True**. 새 조합을 inner가 선택한 경우 `artifacts/v17/cancer_model_v17_experimental.pkl`에 모든 구성 모델·전처리기를 포함해 전체 train으로 재학습한 실험용 모델을 저장했습니다. `new_selected_variables.csv`는 추가 모델의 실제 최종 입력입니다. 기존 구성 모델의 선택 열과 전처리도 피클 안에 들어 있습니다. 전체-train 모델을 개발 성능 평가에 사용하지 않았고 이 피클로 기존 홀드아웃을 평가하면 누수입니다. 독립 프로세스 train-only 재로딩: **passed**.

`artifacts/v17/`의 protocol, inner_results, inner_selected, outer_results, comparison, oof_probabilities, metrics, verification 파일에 근거를 보관합니다. 모델과 캐시는 Git 제외 대상입니다. 이번 결과로 기존 v6 주 모델과 과거 제출 파일을 자동 교체하거나 커밋·푸시하지 않습니다.

## 기존 스트레스 조건의 고정 조합 진단

이전부터 관찰한 seed 43 개발 분할에서 조합을 바꾸지 않고 기존 스트레스 조건도 확인했습니다. rare background는 해당 학습 fold에서 얻은 변이를 검증 입력에 합성 추가하며, 중복 조건은 같은 문자열을 반복합니다. 원본 train/test 파일을 변경하지 않습니다. test의 실제 분포를 모사하거나 Public 향상을 증명하는 실험은 아닙니다. 추가 모델은 각 학습 fold에서 새로 적합했습니다. SHA256·개발 인덱스·클래스가 맞는 기존 v10 train-only OOF만 재사용하고, 캐시가 없으면 기준 모델도 재학습합니다. 이 진단으로 조합이나 비율을 재선택하지 않았습니다.
