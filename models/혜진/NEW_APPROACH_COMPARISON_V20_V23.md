기준 v19의 사용자 확인 Public은 **0.3664759128**입니다. 새 버전 Public은 아직 없습니다. 7개 독립 모델, 새 모델 평균, 선택적인 기존 모델 혼합을 비교했습니다. 아래 값은 같은 개발 분할의 Macro F1이며 기존 홀드아웃 점수가 아닙니다. 원래 20~22 가설과 23의 적응적 후속 탐색을 구분합니다.

## 해석과 데이터 경계

v20·v21은 독립 후보와 혼합이 낮아 v19를 유지했습니다. v22는 원본/새 분할 F1이 개선됐지만 희귀 변이 추가에서 하락해 채택하지 않았습니다. 이 결과를 본 후 v23은 학습 fold에서만 희귀 변이를 추가하고, 더 강한 새 난수의 변형도 검증하도록 고정했습니다. 이를 독립적인 외부 검증이나 실제 test 분포 재현으로 해석하지 않습니다. 같은 환자·분할을 여러 번 관찰한 설계 편향은 남습니다.

새 단독 모델이 좋으면 기존 모델 없이 선택할 수 있게 구성했습니다. 실제로 기존 모델이 포함됐다면 해당 내부 검증에서 그 조합이 높았기 때문입니다. 정확도가 높아도 Macro F1이 낮은 후보는 채택하지 않았습니다. 낮아진 원인은 복합 변경의 분해 실험 없이 특정 전처리 하나로 단정하지 않았습니다.

모든 통계·선별·스케일·TF-IDF·유사도·증강 분포는 학습 fold 내부에서 적합했습니다. 증강본은 부모의 학습 fold 안에만 남습니다. test/sample은 연구에 사용하지 않고, 통과한 모델에 한해서 사용자 승인 최종 추론 단계로 CSV를 만들 수 있습니다. 모델 없는 미채택 버전에는 다른 모델 CSV를 이름만 바꿔 만들지 않습니다.


## v23 고정 후속 진단

원래 +0.005 screening은 미달로 유지합니다. 원래 inner 다수결 조합을 변경하지 않은 후속 진단에서 v19 **0.479842 → 후보 0.493083**, 차이 **+0.013242**, 조건부 CI `[0.0059401012285766564, 0.020846468579992648]`, 강도 35 차이 **+0.025338**, 기존 강도 20·중복 차이 `{'clean': 0.011412247197520467, 'duplicate_tokens': 0.005805386812704612, 'synthetic_rare_background': 0.0300081698801228}`였습니다. 후속 진단 기준 통과: **True**, 모델 저장 **True**. 이 추가 탐색으로 원래 사전 기준을 통과로 바꾸지 않습니다. 동일 개발 환자 재분할의 적응 편향을 인정하며 Public 향상은 미확인입니다.
