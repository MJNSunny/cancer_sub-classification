# v28 — v25 중심 고정 앙상블의 그룹 5-fold 확인

## 출발점과 목표

사용자가 2026-11-11 보고한 v25 Public은 **0.390417094**입니다. 이전 v19 **0.3664759128**보다 **+0.0239411812** 올랐습니다. 목표 0.50은 **실제 제출 점수 목표**이며 로컬 0.50과 구분합니다. v25와 v19는 여러 변경이 있으므로 상승분 전체를 X/* 통일의 효과로 단정하지 않습니다.

v26·v27은 단독 그룹 검증에서는 v25보다 낮았습니다. 그러나 모델별 오차가 다를 수 있어 v25를 중심으로 작은 비중의 새 표현을 결합하는 고정 가설을 시험했습니다. **v25 80% + v26 10% + v27 10%**를 기존 OOF 혼합 결과를 보기 전에 정했고, 그리드 탐색이나 최적 가중치 선택을 하지 않았습니다.

## 1차 3-fold 탐색

- v25 평균 F1: **0.493083**
- 고정 조합 평균 F1: **0.500519**
- 평균 차이: **+0.007436**, 세 fold 모두 상승.

이 결과를 본 뒤 사용자가 5-fold 확인을 요청했습니다. 기존 3-fold 결과와 아래 5-fold 결과를 합쳐 하나의 검증 점수로 보고하지 않습니다. fold 수 변경은 확인 결과를 보기 전에 결정했습니다.

## 5-fold 설계

- 기존 개발 환자 **4,960명**을 seed28028 그룹 5-fold로 나눴습니다. 각 모델은 개발 집합의 약 80%(3,968명)에서 학습합니다. 공식 train 전체 6,201명의 80%라고 표현하지 않습니다.
- 보류 1,241명은 평가하지 않았습니다. 개발 환자들을 이전부터 반복 관찰했으므로 같은 환자의 재분할이며 독립 외부 검증은 아닙니다.
- 동일 raw/정규화 프로필은 같은 그룹이며 학습/검증 그룹 교집합이 없습니다.
- **5-fold × 3버전 = 15개 구성 모델**을 새로 fit했습니다. 전체 train 피클은 CV에 사용하지 않았고, 검증 환자가 들어간 모델로 검증 예측을 생성하지 않았습니다.
- v25의 기존 고정 구조와 증강·선별을 유지했습니다. v26/v27은 fold 안의 별도 그룹 inner validation으로 회수를 정하고, outer 학습 전체에서 어휘와 모델을 다시 fit했습니다.
- 모든 데이터 기반 DF·변수 선택·스케일러·증강 풀은 해당 학습 부분만 사용했습니다. Geneformer는 공식 고정 유전자 임베딩이며 경쟁 환자로 추가 fit하지 않았습니다.
- CPU/RAM을 고려해 worker를 최대 2개 병렬 실행했습니다. runtime worker.py/helpers.py는 노트북 안 소스로 생성되며 외부 프로젝트 Python 파일에 의존하지 않습니다.
- 학습 fold에서만 만든 희귀 변이 풀을 이용해 평균 35개 추가의 합성 스트레스를 새 난수로 확인했습니다. 실제 test 분포를 재현했다고 주장하지 않습니다.

확인 기준은 결과 전에 평균 F1 +0.003, 각 fold -0.001 이상, 고정 OOF의 그룹 bootstrap pooled 차이 95% 하한>0, 희귀 변이 추가 평균 차이 -0.003 이상으로 고정했습니다. bootstrap은 고정 예측의 조건부 불확실성이며 전체 학습·선택 과정을 포함하는 신뢰구간이 아닙니다.

## 형제 라벨 규칙 별도 감사

`LABEL_STRUCTURE_AUDIT_V28.md`에 train만으로 동일 프로필의 라벨 구조와 무작위 행 분할 진단을 기록했습니다. 그룹 검증에서 효과를 측정할 수 없는 중복 의존 규칙을 정상 그룹 검증 성능에 합치지 않았습니다. 동일 프로필은 환자 동일성의 증명이 아니며, test 정답이 반대 라벨이라는 보장도 없습니다.

해당 대회 규칙 페이지는 자동 접근 시 로봇 확인으로 본문을 읽지 못해 허용/금지를 판정하지 않았습니다. 다른 대회의 규칙을 대신 적용하지 않았습니다. **이번 v28 기본 모델과 제출 CSV에 형제 라벨 반전이나 COAD prior 보정을 적용하지 않았습니다.**

## 최종 모델·재현·제출

배포용 v28은 검증된 전체 train v25/v26/v27 모델을 고정 비중으로 결합했습니다. 이 재사용은 배포 단계에 한하며, 위 CV에는 각 fold에서 새로 학습한 모델만 사용했습니다. 이전 전체 모델이 없으면 노트북에 포함된 원래 레시피로 재학습합니다(v26 tree165회, v27 tree98회 고정). 재학습 피클의 메타데이터/해시는 달라질 수 있으므로 원래 파일 해시와 동일하다고 요구하지 않습니다. 모두 같은 train SHA256·유전자 순서·암종 순서인지 확인합니다.

- `cencer_v28.ipynb`: 구성 모델 소스, 그룹 5-fold 확인, 모델 저장, 최종 추론 포함.
- `artifacts/v28/cancer_model_v28_fixed_blend_experimental.pkl`: 전체 조합과 정규화를 포함. `predict_frame(frame)` 반환 열은 `classes_` 순서.
- `artifacts/v28/confirmation_results.csv`, `confirmation_oof.npz`, `verification_v28.json`: 확인 결과·근거.
- `submission/혜진_submission_v28_fixed_blend_experimental.csv`: 고정 모델 최종 추론 결과, Public 미확인.
- `requirements-v28.txt`, `selected_variables_v28.md`.

기존 v25 모델·CSV와 원본 데이터는 보존했습니다. test/sample은 연구 프로세스에서 접근 차단하고 최종 추론에서만 사용했습니다. 기존 legacy-X 가정이 과거 test 표기 관찰 뒤 도입됐다는 설계 출처는 유지합니다. 이 실험에서 test 라벨·분포로 비중을 조절하지 않았습니다. 모델·확률·캐시는 Git 제외 artifacts에 보관합니다.

## 실행 형식 복구

최초 실행에서 15개 모델 학습이 끝난 뒤 NumPy object-string class 배열의 로딩이 차단되어 집계가 중단됐습니다. class 메타데이터만 명시적 Unicode로 변환했고 모든 학습/검증 인덱스와 clean/noise 예측 확률이 byte 단위로 동일함을 확인했습니다. 원본 캐시와 최초 학습 로그, dtype_recovery.json을 보존했습니다. 재학습·가중치 변경·입력 CSV 변경 없이 집계를 재실행했고, 노트북 worker도 Unicode 저장으로 수정했습니다. 최종 노트북의 집계 재실행이 캐시를 썼다는 점과 최초 학습 자체가 모두 새로 수행됐다는 점을 구분합니다.
