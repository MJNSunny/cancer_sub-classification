# 혜진 v6 실험 보고서

팀원 문서를 참고해 v5 고정 대조군과 신규 설정 12개를 같은 3-fold 그룹 CV에서 비교했습니다. 이전 59개를 재탐색하지 않았습니다. 원본 프로필을 그룹으로 묶고 기존 홀드아웃 1,241명을 개발 CV에서 제외했습니다.

## 검증 결과
채택 여부: **True**. 선택 후보: `v5plus_gated_s3_aug_global_lgb4096_0.25`. 최종 구성: `[('v5_reference', 0.75), ('gated_s3_aug_global_lgb4096', 0.25)]`.

| 개발 CV macro F1 | 0.432215 | 0.435576 |
| 개발 CV 희귀 변이 추가 F1 | 0.339619 | 0.345775 |
| 개발 CV 선택 점수 | 0.404524 | 0.408408 |
| 다른 분할 clean F1 | 0.428232 | 0.430573 |

최종 모델 기존 홀드아웃 macro F1 **0.472989**, accuracy **0.463336**, weighted F1 0.467778입니다. 이 홀드아웃과 개발 데이터는 반복 관측했으므로 선택 편향이 있습니다. 팀원의 다른 검증 분할 0.4965와 직접 우열을 판단할 수 없습니다. **v6 Public 점수는 아직 모릅니다.** v4 Public은 사용자 제공 0.3169555443, v5 Public은 아직 제공되지 않았습니다.

## 적용 근거와 한계
팀원 문서의 직접 XGBoost/LightGBM 입력과 절대 변이 개수 보존은 v5에 이미 있었습니다. 새로 global 4,096개, 암종별 선별 2,048/4,096개, 학습 라벨에 따른 KL 특이도 가중치를 비교했습니다. 자세한 정의는 노트북 2절에 있습니다. 학습 데이터에서 변별력이 크다는 사실은 임상적 드라이버/병원성 증명이 아닙니다.

암종별 선별은 one-vs-rest 양성 방향 chi2 순위를 번갈아 채택하고, 신규 선별에서는 학습 열이 완전히 같은 경우만 중복 제거합니다. 전역 상관 임계값 0.98은 v5 구성에만 적용됩니다. 숫자 요약은 신규에서 강제로 보존합니다. specificity 후보는 변이 부분만 정규화하고 원시 변이 부담 등 숫자 요약은 별도로 보존합니다.

모든 사전·지원도·선별·특이도·스케일러는 해당 학습 fold로만 적합합니다. test 빈도나 정답은 사용하지 않습니다. test에 많은 변이를 일반인 유래라고 확정하지 않고, 위치 ±3을 무조건 같게 보지 않으며, class 비율 강제 맞추기를 하지 않습니다. 570개 예측이 모두 정답이라는 주장은 테스트 정답 없이는 확인 불가입니다.

## 실제 최종 변수
전체 목록: artifacts/v6/final_features.csv. 모델별 이름·가중치·입력 수는 model_sizes.json에 있습니다. 이전 v5 혼합을 포함하는 경우 기존 구성의 파싱·Pearson 선별·지원도 설정도 유지됩니다. 각 모델의 입력 수를 합산하면 16,384개이고, 이는 고유 유전자 수가 아닙니다. 신규 모델을 추가할수록 계산량과 크기가 증가할 수 있습니다.

모델 83.07 MiB, v5 대비 예측 변경 208개입니다. 변경 개수는 정답 증가 수가 아닙니다. 피클은 프로젝트 코드 없는 임시 폴더에서 전체 test 예측을 재생성했고 확률·CSV·ID·배치 일치를 확인했습니다. 원본 데이터와 설치 환경은 필요합니다.

## EDA와 최종 변수 해석 파일

eda_by_class.csv에는 암종별 환자 수·변이 유전자 수 평균/중앙값/최대값, eda_mutated_gene_burden.csv에는 train/test 기술통계, eda_missing_by_gene.csv에는 유전자별 결측 수가 있습니다. test 통계는 설명에만 사용합니다.

final_feature_importance.csv는 실제 최종 변수별 트리 중요도, 최대 절대 선형 계수 또는 신경망 첫 층 가중치 norm입니다. 모델 사이에서 수치 크기를 직접 비교할 수 없으며, 임상적 인과성이나 개별 환자의 기여도를 뜻하지 않습니다. 상위 10개씩은 top_features_by_model.csv에 있습니다.
