# v21 — 기존 앙상블을 강제하지 않은 새 방식 비교

## 목적과 근거

기존에 검증한 hierarchical 표현을 유지하고, 이진 변이 집합 Tanimoto 또는 TF-IDF-RBF 유사도를 사용하는 SVC를 새로 학습했습니다. 커널은 90% 범주형 유사도 + 10% 별도 변이량 RBF로 고정했고 C=4, balanced입니다. softmax(OVR margin/2)는 조합용 점수 정규화이며 독립 데이터로 보정된 posterior가 아닙니다. 따라서 확률 합 검증을 calibration 성능 검증으로 해석하지 않습니다.

v19 단독, 새 모델 단독, 새 모델 평균, v19를 선택적으로 포함하는 고정 혼합을 후보에 넣었습니다. 모델·변수·혼합 비율은 outer 결과를 본 뒤 바꾸지 않았습니다. v20 이후 후속 가설은 앞 단계 결과를 보고 추가했으므로 적응적 탐색임을 인정하며, 세 버전의 outer 최고값을 다시 최종 성능으로 골라 쓰지 않습니다.

기준은 사용자에게서 실제 제출 결과를 받은 **v19 Public 0.3664759128**입니다. 이는 CV와 다른 지표 기록이며 이번 후보의 Public 점수는 없습니다. 과거 v10 최고 0.3493803489 대비 v19 향상은 +0.0170955639입니다.

## 누수 경계와 고정 검증

공식 train 6,201명 중 기존 개발 4,960명으로 검증했습니다. raw/정규화 동일 프로파일은 같은 그룹으로 묶었습니다. 기존 홀드아웃 1,241명은 재평가하지 않았고 test/sample은 연구 프로세스 open guard로 차단했습니다. 어휘·빈도·TF-IDF·쌍 shortlist·chi2·스케일·유사도·발생비율·모델은 각 학습 fold에서만 적합했습니다. 단순 파싱은 점별 고정 규칙입니다.

outer 3-fold seed 17017, inner 2-fold seed 17018+fold를 사용했습니다. 이 분할과 환자들은 이전부터 관찰한 개발 데이터이며 독립 외부 검증이 아닙니다. v19 캐시는 train SHA256·프로토콜·학습/검증 인덱스가 일치할 때만 재사용하고 없으면 해당 학습 환자로 재학습합니다. 전체-train 저장 피클은 CV에 사용하지 않았습니다.

사전 1차 기준: nested 선택의 평균 delta +0.005 이상·각 fold -0.001 이상. 통과한 경우에만 사전 지정 새 seed의 그룹 3-fold에서 inner 다수결 조합을 고정해 확인합니다. 추가 기준: 평균 +0.003·각 fold -0.001 이상·고정 OOF 그룹 bootstrap pooled delta 95% 하한 >0. 통과 시 기존 seed 43의 합성 희귀 변이·중복 조건 평균 delta -0.003 이상도 확인합니다. 이 기준을 결과에 맞춰 완화하지 않았습니다. bootstrap은 고정 OOF 조건부이며 학습 과정 전체의 불확실성을 포함하지 않습니다.
