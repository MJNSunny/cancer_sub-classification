# v11 변수 비교 및 미채택 이유

유전자×변이 유형 존재 여부를 이진 입력으로 사용했습니다. 원본 학습 fold의 환자 관측 빈도 1/3/5/10 이상인 변수만 남긴 뒤 chi2로 512/1024/2048/4096개를 선택했습니다. chi2는 암종과의 통계적 연관성이며 원인 관계가 아닙니다. 빈도 필터와 정답 기반 선별 모두 검증 환자를 제외한 학습 부분에만 적합했습니다. 서로 다른 fold는 실제 변수 목록이 다를 수 있습니다.

ComplementNB alpha=0.1, type 표현, 기존 v6는 고정하고 확률 비중만 10/15/20/25%로 비교했습니다. 유전자명과 변이 유형을 조합한 항목이므로 변수 수와 고유 유전자 수는 다릅니다. 최종 후보에 마스킹·새 SVM·새 수치형 변수를 추가하지 않았습니다.

최고 후보는 기존 v10의 4096개·최소 빈도 1·25%와 같고 반복 노이즈 기준을 통과하지 못했습니다. 따라서 v11 전용 최종 학습 변수 목록이나 모델을 새로 만들지 않았습니다. 기존 v10 실험용의 전체 train 선별 목록은 selected_variables_v10.md 및 artifacts/v10/experimental_new_features.csv에 있습니다. 이는 v11 각 fold에 공통으로 고정한 목록이 아닙니다.
