# v24 — 옛 종결 표기 X/* 통일 실험

## 변경과 가정

사용자 요청에 따라 표준 아미노산 한 글자 + 양의 위치 + X인 독립 토큰을 같은 위치의 `*`로 정규화합니다. 예: `R1450X` → `R1450*`, `p.R1450X` → `p.R1450*`. `X1450R`, `R0X`, `G12insX`, `R12Xfs`, 범위 및 불확실성 괄호는 변경하지 않습니다. 모든 X를 전역 치환하지 않습니다. 표준 한 글자 아미노산은 ACDEFGHIKLMNPQRSTVWY입니다.

옛 HGVS에서 X는 종결을 나타냈으며 현재는 Ter/*를 사용합니다. 현재 X는 미상 아미노산이므로 이 데이터의 X가 실제로 옛 종결이라는 점은 아직 확인되지 않은 가정입니다.
- [HGVS 변경 이력](https://archive.hgvs-nomenclature.org/versioning/)
- [현행 불확실성 표기](https://hgvs-nomenclature.org/main/recommendations/uncertain/)

## 기반 모델과 학습

v23 후속 실험 모델의 선별 변수, 스케일러, 모든 학습 계수와 앙상블 비중을 그대로 보존합니다. v19 60% + train 희귀 변이 증강 OVA 부스팅 20% + 증강 MLP 20%입니다. train 전체를 검사했을 때 이번 정규화로 변경되는 입력이 없었습니다. 따라서 같은 train으로 다시 학습하지 않고 정규화와 기존 학습 모델을 한 피클에 저장했습니다. 재학습하거나 하이퍼파라미터를 새로 탐색한 버전으로 표시하지 않습니다.

`cencer_v24.ipynb` 안에는 기반 v23의 선별·검증·학습 코드도 모두 포함되어 있습니다. 기반 모델이 없으면 앞부분부터 실행하고, 이미 있으면 마지막 v24 생성 셀을 실행합니다. 별도 프로젝트 Python 파일에 의존하지 않습니다. 기반 v23의 원래 screening 미달과 적응적 후속 진단이라는 한계도 유지됩니다.

## 실제 확인 결과

- 전체 train 6,201명의 입력이 정규화 전후 정확히 같습니다.
- train 종결 표기를 합성 X 표기로 바꾸면 3,266명의 입력이 변경됩니다. 이를 v24 정규화로 복원한 결과 전체 입력이 원본과 정확히 같습니다.
- 종결 표기를 가진 train의 앞 96명을 대상으로 기반 모델 원본 입력 예측과 합성 X 입력 예측을 비교했습니다. 기존 처리의 원본 예측 일치율은 **92.71%**, v24는 **100%**입니다. 최대 확률 오차는 `6.938893903907228e-18`입니다.
- 96명은 이미 학습에 포함된 샘플입니다. 위 수치는 정확도·매크로 F1·독립 검증 성능이 아니라 **입력 표기 변경에 대한 예측 불변성**입니다.
- 제한적 치환/비치환 사례 10개, 배치 순서 독립성, 저장 후 재로딩 예측을 확인했습니다.
- 새 CV 정확도와 F1은 측정하지 않았습니다. 기반 v23의 후속 분할 평균 Macro F1 **0.493083**은 참고값이며 v24의 새 개선 점수로 주장하지 않습니다. 원래 기준 통과 모델이라는 의미도 아닙니다.
- v24 Public 점수는 미확인입니다. 기존 사용자 확인 최고 Public은 v19 **0.3664759128**입니다.

## 누수와 설계 출처

이 변경은 test 표기 차이를 관찰한 뒤 사용자와 상의해 정한 가정입니다. **test와 무관하게 사전 결정한 설계라고 주장하지 않습니다.** test 정답을 사용하지 않았으며 test를 fitting, 변수 선별, CV, 비중·하이퍼파라미터 최적화에 넣지 않았습니다. v24 모델 생성·합성 검증 프로세스는 test/sample 파일 접근을 차단했습니다. 이후 고정된 모델의 제출 추론에서만 별도 프로세스로 test/sample을 읽습니다. 리더보드 상승은 별도로 확인해야 합니다.

## 산출물

- `cencer_v24.ipynb`: 기반 모델 재현 코드 + 제한적 정규화 + 저장·검증 + 최종 추론
- `artifacts/v24/cancer_model_v24_legacy_stop_experimental.pkl`: 정규화 포함 전체 모델. cloudpickle로 로드하고 `predict_frame(gene_frame)` 호출. 반환 확률 열은 `classes_` 순서입니다.
- `artifacts/v24/verification.json`: 합성 검증 결과와 모델·train SHA256
- `submission/혜진_submission_v24_legacy_stop_experimental.csv`: 최종 추론 제출 파일
- `requirements-v24.txt`: 기반 v23과 동일 환경

변수 수를 새로 늘리거나 test 유래 유전자 목록을 만들지 않았습니다. 원래 여러 변이 토큰은 보존하고, 정확한 반복 토큰 제거는 기반 파서의 기존 처리에 맡깁니다. Geneformer나 쌍둥이 라벨 변경 규칙은 이번 버전에 추가하지 않았습니다.
