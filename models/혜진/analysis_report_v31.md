## 사용자 제약과 현재 구조

최종 **4개**(LR, LightGBM multiclass, ComplementNB, LightGBM OVA), 공유 parser/전처리1개입니다. 5개는 별도 허락 전에는 사용하지 않으며 이번에는 추가하지 않았습니다. 새 모델·기존 모델 피클을 앙상블에 더 붙이지 않았습니다. 기준 v30의 학습된 피클을 불러오지 않고 각 fold에서 새로 적합했습니다.

문헌 근거와 parser 범위는 v16/v30의 P05/P06/P10/P41~43/P47~50을 계승합니다. 이번에 새로50편을 다시 검색/정독했다고 주장하지 않습니다. 외부 환자/정답/사전학습/문헌 gene panel을 추가하지 않고 Geneformer·쌍둥이 라벨 반전·강제암종 비율 보정은 미사용입니다. 같은 과거 개발 환자에 대한 누적 연구 편향은 남습니다.

## 비교 설정: 한 번에 한 요소만 변경

- alpha5→2: exact residual df/(df+alpha)의 감쇠만 완화. **MaxAbs 이후** 적용하여 scaling이 차이를 상쇄하지 않게 함. 임상 병원성 점수가 아님.
- k8192→6144: 학습 DF 조건 이후 chi2 변수 수만 축소. gene·유형·AA·희귀·변이량 표현을 없애거나 test에서 유전자 목록을 고르지 않음. 실제 최종 선택 목록은 별도 파일.
- 증강20→0/10: OVA의 원래 학습 행 기반 Poisson nuisance만 제거/완화. 원래 행 가중치/증강0.5와 mask0.1는 유지. 증강0에는 mask도 적용하지 않음.
- 비중: 기존 0.226891/0.226891/0.126050/0.420168와 균등0.25만 비교. 가중치 grid·메타 분류기·pair 전문가 없음.

각 설정은 단일 변경이며 우승 요소를 outer 결과를 보고 조합하지 않습니다. 증강0/10의 내부 비교에서는 같은 inner-training의 기준 LR/LGB/CNB와 동일 전처리를 재사용하고 OVA만 다시 fit합니다. 균등 평균은 같은4개 예측에 비중만 바꿉니다. 서로 다른 fold 사이의 fitted 모델을 재사용하지 않습니다. alpha/k가 바뀌면4개 모두 새로 fit합니다.

## 실제 nested 분할과 선택 규칙

개발4960명, 기존 보류1241명은 평가하지 않습니다. 원본train6201명과4384개 gene,26개 라벨을 사용합니다. ID는 입력에서 제외, 같은 원본/canonical profile의 보수적 그룹은 함께 배치하고 보류 그룹과도 분리합니다. train SHA `92418b8441d058cfc68e939dd88725610750be4bc8edc51253cffc72fc4fc0ab`.

outer는 seed31032/31033의 그룹5fold씩10개입니다. 각 outer 학습부 안에서만 seed31100+10×repeat+fold의 inner그룹2fold로6개 설정을 비교합니다. inner 평균 clean 차이≥0.001·최악≥-0.005·noise평균≥-0.003인 변경 후보 중 평균F1 최고를 선택하고, 없으면 기준을 유지합니다. 동률은 고정 설정 순서입니다. 선택 JSON을 저장한 후 outer 학습부로 기준과 후보를 새로 fit하고 **그 다음에** outer 정답으로 평가합니다.

어휘·event DF·rare/지원·chi2·MaxAbs·exact 감쇠는 해당 inner 또는 outer 학습부에서만 fit합니다. training 희귀 통계는 자기 자신 제외, 추론은 그 학습부의 DF만 사용합니다. 노이즈 pool도 해당 학습부만 사용합니다. 원래 학습 행으로 전처리를 fit한 뒤 증강에는 transform만 합니다. 전체train 행렬/피클을 CV에 넣지 않습니다.

당초 전역3fold 선택 후 seed를 바꾼 반복 확인을 준비했으나, 같은 환자의 정답이 앞선 설정 선택에 들어가는 한계를 확인해 **진짜 nested**로 바꿨습니다. 중단된 partial pilot은 artifacts/v31/aborted_global_screen에 보존하며 최종 점수에 섞지 않습니다. 비교6개/선택·개선 기준은 결과에 맞춰 완화하지 않았습니다. nested가 현재 설정 선택의 outer 정답 사용은 막지만 과거 v1~v30 설계 이력까지 소급 제거하지는 않습니다.

외부10fold가 독립인 것처럼 표준오차를 계산하지 않습니다. 반복별 성능과 모든 차이를 함께 보고, bootstrap은 profile 그룹을 두 반복에서 동일하게 resample합니다. 조건부 CI는 완전한 nested 재학습 CI가 아닙니다. 임상적 안전성·외부 코호트 일반화의 증거로 쓰지 않습니다.
