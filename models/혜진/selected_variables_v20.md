# v20 변수 및 학습 선택 기록

TF-IDF 변이 표현 + 별도 변이량 수치, 학습 chi2 상위 128개 유전자에서 동시 변이 쌍 생성, TF-IDF 로지스틱·발생비율 가중 OVR 선형 모델·위치 중심 LightGBM을 독립 학습했습니다. min_df 2/3, linear 최대 20,000열, tree 최대 10,000열입니다. 발생비율 선형 모델은 [Wang·Manning 2012](https://aclanthology.org/P12-2018/)의 log-count-ratio 아이디어를 참고했지만, 여기서는 환자별 발생률·TF-IDF·logistic·별도 변이량을 사용하므로 원 논문 SVM을 재현한 것이 아닙니다. 유전자 쌍은 DNA 변이 문맥이나 생물학적 상호작용의 증명이 아닌 동시 관측 특징입니다.

최종 조합: `v19_reference`. 새 전체-train 모델 저장: **False**.

독립 학습한 fold 모델들은 비교용입니다. 모든 inner가 기존 기준을 선택하거나 사전 기준을 통과하지 못하면 배포용 새 변수·모델·CSV를 임의로 만들지 않습니다. 기존 v19가 유지됩니다.
