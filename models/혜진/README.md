## 실행 방법

1. 저장소의 `data/` 폴더에 대회 제공 파일 `train.csv`, `test.csv`, `sample_submission.csv`를 배치합니다. 데이터는 Git에 올리지 않습니다.
2. Python 환경을 만들고 `requirements-v29.txt`의 패키지를 설치합니다. 원래 실행 환경을 기록한 파일이며, 다른 Python·패키지 버전에서의 호환성은 별도 확인이 필요합니다.
3. 저장소 안에서 노트북을 실행합니다. 모델 크기 비교에 필요한 기준 산출물을 남기려면 `cencer_v25.ipynb` 실행 후 `cencer_v29.ipynb`를 실행합니다. 학습 코드는 노트북에 포함돼 있습니다.
4. 학습 산출물은 `artifacts/`에, 최종 예측 CSV는 저장소의 `submission/`에 생성됩니다.

특징 사전, 변수 선택, 스케일링, 증강 통계는 해당 학습 구간에서만 적합합니다. 동일 프로필은 같은 검증 그룹으로 묶습니다. 대표 모델 v29에는 중복 프로필의 라벨을 덮어쓰는 규칙과 test 암종 비율 강제 보정을 사용하지 않았습니다.
