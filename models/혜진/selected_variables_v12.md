# v12 변수 선별과 규제 비교

입력은 유전자×변이 유형 존재 여부의 이진 특성입니다. 임상 기능 확정이나 원인 관계가 아닌 학습 데이터의 연관성을 이용합니다. 비교 예산은 2048/4096개이며 가용 변수보다 많으면 가용 변수 전체를 사용합니다.

- global: 외부 학습 부분 전체의 다중 암종 chi2 순위.
- classwise: 각 암종 대 나머지 이진 chi2 중 해당 암종에서 관측 비율이 높은 변수만 양성 연관 후보로 둡니다. 암종별 ceil(k/26)개 quota를 합친 뒤 전체 chi2 순위로 k개에 맞춥니다. 부족하면 전체 순위에서 채웁니다. 암종별 완전히 동일한 최종 할당을 보장하지는 않습니다.
- stable: 외부 학습 부분 안의 그룹 3-fold 각각 학습 환자로 chi2 상위 k개를 구합니다. 선택 횟수 내림차순, 평균 순위 오름차순으로 최종 k개를 고릅니다. 두 번 이상 선택된 변수만이라는 절대 문턱은 적용하지 않으며 예산을 채울 때 낮은 빈도 변수도 포함될 수 있습니다.

선별을 한 번 수행한 후 alpha 0.03/0.1/0.3/1/3을 비교합니다. alpha가 클수록 빈도 추정이 평활화되며 실제 오류 감소를 보장하지 않습니다. 혼합 비중은 모든 환자에게 동일하게 15/25%입니다. 환자별 게이팅은 제외했습니다.

어휘·선별·모델은 외부 학습 부분에만 적합하고, stable 내부 선별에도 외부 검증 정답을 넣지 않았습니다. 같은 원본 프로필 그룹은 분할 간 겹치지 않습니다. test는 후보 선별과 학습에서 제외했습니다.

설정별 비교는 artifacts/v12/model_comparison.csv, 반복 결과는 confirmation_cv.csv, 사전 기준은 search_protocol.json, 최종 상태는 selection.json입니다. 채택 후보가 있으면 전체 train 학습에서 선택된 신규 변수는 selected_new_features.csv에 저장합니다. 없으면 최종 신규 변수 목록을 만들지 않습니다.
