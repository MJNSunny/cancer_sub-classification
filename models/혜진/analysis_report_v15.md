# v15 — 쌍별 분류기 입력 단순화·학습 전용 희귀 변이 증강

**결론: 사전 채택 기준 미달, 새 제출 권고 없음.** test/sample은 열지 않고 기존 홀드아웃도 재평가하지 않았습니다. 새 제출 CSV는 만들지 않았습니다. v10은 확인된 Public 기준 모델로 보관합니다.

## 가설과 고정한 것

v14는 원본 F1이 조금 올랐으나 seed 211의 합성 노이즈 F1이 0.006179 낮아졌습니다. 정확한 변이/위치에 대한 의존을 줄이고 학습 부분에만 희귀 변이를 추가하면 이 취약성을 줄일 수 있는지 비교했습니다. GBMLGG/LGG, KIPAN/KIRC 두 쌍, empirical LR C=0.1, chi2 최대 512개, 고정 alpha=0.5는 유지했습니다. 환자별 혼합 비중/게이팅은 사용하지 않았습니다.

## 여섯 개 대조 실험

raw/gene/type × 증강 없음/Poisson 평균 10개 주입입니다. gene은 gene·numeric·module, type은 gene·type·numeric·module를 남깁니다. 숫자와 경로 요약은 모든 표현에서 유지하므로 gene 입력을 순수 유전자 이진값만으로 설명하지 않습니다. 같은 파서·정규화·LR·선별 예산을 사용했습니다.

희귀 변이 풀은 해당 외부 fold 학습 환자 전체에서 관측 환자 2명 이하인 동의/치환 변이를 모아 두 종류를 50:50으로 샘플링했습니다. 검증 환자는 풀 생성에서 제외했고 두 암종 모두 같은 풀을 사용했습니다. 증강본은 원본 학습 환자에게만 붙였으며 별도 분할로 이동하지 않았습니다. 어휘·빈도·chi2·MaxAbs는 원본 쌍 학습 부분에서만 적합했습니다. 증강에서만 나온 열을 추가하지 않았습니다. 원본/증강 가중치 1:0.5를 합계가 원본 환자 수가 되도록 정규화해 정규화 강도가 표본 수 증가만으로 바뀌지 않게 했습니다.

이것은 라벨 보존이 생물학적으로 확정된 변환이 아니라 합성 가정입니다. 평가 noise 평균 20개와 학습 noise 평균 10개의 난수 seed는 분리했습니다.

## 분리·재현

고정 원본 그룹 및 정규화 프로필이 각 학습/검증 양쪽에 걸치지 않음을 확인했습니다. baseline cache는 train 해시·개발 행·클래스 및 기존 재분할 점수를 확인한 뒤 재사용했습니다. 캐시가 없으면 같은 학습 부분으로 baseline도 이 노트북 안에서 재학습합니다. 외부 검증을 조기 종료나 feature fitting에 사용하지 않았습니다. 과거 버전에서 test EDA와 반복 홀드아웃을 관찰한 설계 편향이 없어졌다는 주장은 하지 않습니다.
