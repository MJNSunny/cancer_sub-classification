# v25 변수 선별

구조와 비중은 v23의 고정 조합을 따르지만, 모든 fold 및 전체 train에서 변수 선별을 새로 수행했습니다. 추가 OVA/MLP의 DF 기준 3 및 chi-square 최대 8,192열 선별, MaxAbsScaler, 희귀 변이 가중치는 해당 학습 데이터에서만 fit했습니다. 기반 앙상블도 원래 각 구성의 선별·학습 과정을 새로 fit했습니다. X/* 정규화는 통계적 선별 전에 공통 적용합니다. 변수명이 종결 표기의 X/* 때문에 분리되지 않도록 합니다. 전체 모델의 실제 변수명은 각 구성 preprocessor 객체에 저장됩니다.
