# 민준 v11 정리: 쉽게 이해하기 (2026-11-10 ~ 11-11)

> 같이 올린 파일 3개
> - `v11_clean.ipynb`: 제출 파일을 만든 노트북
> - `submission.csv`: 11/11에 제출한 파일 (Public LB **0.4475**)
> - `v11_설명.md`: 지금 읽고 있는 이 설명서
>
> 지난번에 올린 **v10과는 다른 버전**입니다. v10에 "표기 통일"을 더하고 설명을 정리한 것이 v11입니다.

## 한눈에 보기

- **무엇을 했나:** 환자의 "유전자 고장 목록"을 보고 26가지 암 중 어떤 암인지 맞히는 모델(v11)을 만들었습니다. 시험지(test)를 미리 보지 않고 만들었습니다.
- **연습 점수(CV):** 0.424 → **0.497**
- **제출 점수(LB):** 0.417 → **0.448**. 같은 조건의 민정 v6(**0.479**)보다는 낮습니다.
- **가장 큰 교훈:** 연습 점수가 높다고 제출 점수도 높지는 않았습니다. test의 1/3이 train과 다른 방식으로 적혀 있기 때문입니다(5번).

---

## 1. 무슨 문제를 푸나요?

- 환자 한 명이 표의 한 줄입니다. 칸마다 유전자 이름이 있고, 고장(변이)이 없으면 `WT`, 있으면 `R175H` 같은 고장 표시가 적혀 있습니다.
  - `R175H`는 "단백질의 175번째 블록이 R에서 H로 바뀌었다"는 뜻입니다.
- 이 고장 목록만 보고 **어떤 암인지(26종)** 맞힙니다.
- 점수(**Macro F1**)는 26개 암을 **과목별로 채점해서 평균**낸 것입니다. 그래서 환자가 적은 암도 많은 암과 똑같이 중요합니다.

## 2. 절대 지키는 규칙: "시험지 미리 보기 금지"

대회 규칙상 **test(시험지)를 학습에 쓰면 수상에서 제외**됩니다. 그래서 이렇게 했습니다.

- 어떤 유전자를 볼지, 숫자를 어떻게 맞출지는 **train(연습문제)만 보고** 정합니다.
- test 환자는 **한 명씩 따로** 처리합니다. 다른 test 환자의 정보는 같이 보지 않습니다.
- 노트북 7절이 이 규칙을 지켰는지 **자동으로 검사**합니다. 통과하지 못하면 노트북이 멈춥니다.

### 애매했던 것들과 팀 결정

| 항목 | 무엇인가 | 결정 | 이유 |
|---|---|---|---|
| 표기 통일 | `R1450X`를 `R1450*`로 읽는 것 등 | ✅ 사용 | 칸 하나만 보고 바꾸는 규칙이라 test 통계를 쓰지 않습니다 |
| 쌍둥이 규칙 | 같은 환자의 다른 이름표로 답하기 (3번 ④) | ✅ 사용 | test를 열어 보지 않아도 train과 공개 지식만으로 알 수 있습니다 |
| COAD 22% | "test의 22%가 대장암"이라고 가정하고 대장암 점수를 올리기 | ❌ 사용 안 함 | **test 예측 결과와 제출 점수를 보고** 알아낸 숫자라서, test를 엿본 것과 같습니다 |

## 3. 모델은 어떻게 생겼나요?

두 모델이 각자 답을 내고, 그 답을 **반반 섞어서** 최종 답을 정합니다.

| 모델 | 비유 | 잘하는 것 |
|---|---|---|
| **LightGBM** | 스무고개 ("TP53이 고장났나? → 예 → APC도?") | 여러 고장이 함께 나타나는 패턴 |
| **로지스틱 회귀** | 점수표 (고장마다 암별 점수를 더함) | 고장 하나하나의 영향을 고르게 반영 |

### 모델에 주는 재료

**① 기본 재료**
- 어떤 유전자가 고장났나
- 유전자가 아예 끊어졌나
- 정확히 어느 위치가 고장났나
- 고장이 모두 몇 개인가

**② Geneformer: 미리 공부한 AI의 "유전자 성격표"** (CV +0.018)
- Geneformer는 세포 1억 개 이상으로 미리 공부한 AI 모델입니다. 대회 규칙상 **사전학습 모델은 사용할 수 있습니다**.
- 이 모델은 유전자마다 "어느 조직에서, 어떤 유전자와 함께 일하는지"를 숫자 768개로 정리한 **성격표**를 갖고 있습니다.
- 환자의 고장난 유전자들의 성격표를 평균 내서 재료로 씁니다.
- 이 재료는 **로지스틱 회귀에만** 줍니다. LightGBM에도 줬더니 숫자 768개에 정신이 팔려 오히려 점수가 떨어졌습니다.

**③ 변이 시그니처: 범인이 남긴 지문** (CV +0.054, 가장 큰 효과)
- 암을 만든 원인마다 DNA에 남기는 **흔적의 모양이 다릅니다**.
  - ☀️ 자외선(피부암 SKCM): C가 T로 바뀌는 흔적
  - 🚬 담배(폐암 LUSC·LUAD): C가 A로 바뀌는 흔적
- 데이터에는 DNA 대신 단백질 변화(`R175H`)만 있습니다. 그래서 생물 시간에 배우는 **유전 암호표**(DNA 3글자 → 아미노산 1개)를 거꾸로 써서 "이 변화를 만든 DNA 흔적"을 추정했습니다.
- 결과: 폐암(LUSC) +0.21, 간암(LIHC) +0.15, 자궁경부암(CESC) +0.13. 실제 생물학과 맞는 방향으로 점수가 올랐습니다.

**④ 쌍둥이 규칙: 같은 사람이 이름표 두 개**
- 암 이름 중 **KIPAN은 "신장암 전체 모음"**입니다. 그래서 KIRC(신장암의 한 종류) 환자가 **KIPAN으로도 한 번 더** 들어 있습니다. **GBMLGG(뇌종양 모음)와 LGG**도 마찬가지입니다.
- 그래서 train에는 고장 목록이 **글자 하나까지 똑같은 두 사람**이 있습니다. 신장에서 270쌍, 뇌에서 173쌍을 찾았습니다.
- 규칙: test 환자의 고장 목록이 train의 KIRC 환자와 똑같으면, 그 사람의 다른 이름표인 **KIPAN**으로 답합니다. 반대 방향(KIPAN → KIRC)과 뇌종양 쌍(GBMLGG ↔ LGG)도 같은 방식입니다.
- train을 무작위로 나눠 연습해 보면, 이 규칙이 발동했을 때 99.7%가 맞았습니다.
- ❓ **연습 점수(CV)는 그대로인데 제출 점수만 오르는 이유:** 우리 연습 시험은 똑같은 사람을 항상 같은 조각에 묶습니다. 그래서 연습 중에는 규칙이 발동하지 않습니다. 실제 시험에서는 쌍둥이가 train과 test로 나뉘어 있어서 그때만 발동합니다.
- ⚠️ **남은 위험:** 모델 실력이 아니라 데이터를 만들 때 생긴 중복을 이용하는 방식입니다. 그래서 "비정상적인 방법"으로 볼 수도 있다는 리뷰가 있었습니다. 끄려면 `USE_TWIN=0`을 씁니다.

**⑤ 표기 통일 (v11에서 새로 추가)**
- `R1450X`를 `R1450*`로 읽습니다. 둘 다 "여기서 단백질이 끝난다"는 같은 뜻입니다.
- 한 칸에 **완전히 똑같이** 두 번 적힌 고장은 하나로 셉니다.
- "위치만 다른 같은 변화"(`M267I M206I`)까지 합치는 것도 시험해 봤습니다. 그런데 train에는 진짜로 그런 이중 고장이 많아서(특히 피부암) 연습 점수가 0.496 → 0.482로 떨어졌습니다. 그래서 그것은 합치지 않습니다.

## 4. 점수 기록

| 실험 | 바꾼 것 | 연습 점수 (CV) | 제출 점수 (LB) |
|---|---|---|---|
| baseline | 기본 재료만 | 0.424 | – |
| gf_lr | + Geneformer 작은 버전 | 0.434 | – |
| gf2_lr | Geneformer 큰 버전으로 교체 | 0.444 | – |
| gf2_sig | + 변이 시그니처 + 쌍둥이 규칙 | 0.496 | 0.417 |
| **norm_twin = v11** (제출한 것) | + 표기 통일 | **0.497** | **0.448** |
| (참고) Geneformer 뺀 버전 | v11에서 `USE_GF=0` | 0.479 | – |
| (참고) 시그니처 뺀 버전 | v11에서 `USE_SIG=0` | 0.443 | – |
| (참고) 민정 v6 | XGBoost + 로지스틱 회귀, 경로·콤보 재료, 표기 통일, 쌍둥이 규칙 | 0.473 | **0.479** |

- 새 아이디어는 연습 점수가 **+0.003 이상** 오르고, 5번 나눠 본 시험 중 **3번 이상** 올라야 채택했습니다. 운으로 오른 것을 걸러내기 위해서입니다.
- 민정 v6의 COAD 22% 보정은 코드에는 있지만, 다시 돌려 확인해 보니 **실제로는 적용되지 않았습니다**. 그러니 0.479는 모델 자체의 점수입니다.

## 5. ⚠️ 가장 큰 교훈: 연습 점수 ≠ 제출 점수

**test의 약 1/3(879명)이 train과 다른 "양식"으로 적혀 있습니다.** 같은 내용을 다른 글씨체로 쓴 시험지라고 생각하면 됩니다.

| | train (연습문제) | test 중 879명 |
|---|---|---|
| 단백질 끝(종결) 표시 | `R1450*` | `R1450X` |
| 한 칸에 적힌 고장 수 | 평균 1.2개 | 평균 1.9개 (같은 고장을 위치만 바꿔 여러 번 적음) |
| 환자당 고장난 유전자 수 (중간값) | 14개 | 53개 |

- 처음 모델은 이 879명 중 **61%를 위암(STES)으로** 예측했습니다. "고장이 아주 많은 환자는 위암·대장암"이라고 배웠기 때문입니다.
- 표기 통일 뒤에는 위암 42%, 대장암 44%로 바뀌었고, 제출 점수가 0.417 → 0.448로 올랐습니다.
- 그래도 **연습 점수 순위와 제출 점수 순위가 반대**입니다. 연습 점수는 v11(0.497)이 민정 v6(0.473)보다 높은데, 제출 점수는 민정 v6(0.479)가 v11(0.448)보다 높습니다.
- 그래서 두 모델 중 어느 쪽이 test에서 나은지는 **연습 점수로는 알 수 없고, 제출 점수로만 확인**할 수 있습니다.

2. `folds.csv` (팀 공통 시험 나누기): 있으면 그대로 쓰고, 없으면 노트북이 새로 만듭니다.
3. Geneformer 파일 4개(약 420MB): Hugging Face `ctheodoris/Geneformer`에서 받아 `pretrained/geneformer_v2/` 아래에 같은 경로로 둡니다.
   - `Geneformer-V2-104M/model.safetensors`
   - `Geneformer-V2-104M/config.json`
   - `geneformer/token_dictionary_gc104M.pkl`
   - `geneformer/gene_name_id_dict_gc104M.pkl`
   - Geneformer 없이 돌리려면 `USE_GF=0`을 씁니다. 단, 그러면 제출 파일과 결과가 달라집니다.
4. 파이썬 패키지: `numpy`, `pandas`, `scipy`, `scikit-learn`, `lightgbm` (Geneformer 파일은 노트북이 직접 읽으므로 `torch`는 필요 없습니다)

### 실행
- **노트북:** `v11_clean.ipynb`를 위에서부터 차례로 실행합니다. 맨 위 설정칸의 기본값이 곧 제출한 설정입니다. 한 번에 약 5분 걸립니다.
- 결과는 `out/<실험명>/submission.csv`에 저장됩니다. 실험명은 설정칸의 `EXP`이고, 기본값은 `baseline`입니다(이름만 다를 뿐 설정은 제출한 것과 같습니다).
- 설정을 바꿔 보고 싶으면 설정칸의 값을 고치면 됩니다.

| 해 보고 싶은 것 | 바꿀 설정 |
|---|---|
| Geneformer 빼기 | `USE_GF=False` |
| 변이 시그니처 빼기 | `USE_SIG=False` |
| 쌍둥이 규칙 끄기 | `USE_TWIN=False` |
| 표기 통일 끄기 (v10과 같아짐) | `NORMALIZE=False` |

### 팀 앙상블에 참여하기
- 가능하면 **`folds.csv`(팀 공통 시험 나누기)**를 써 주세요. 나누는 방법이 같아야 연습 점수를 공정하게 비교할 수 있습니다.
- `team/` 폴더에 두 파일을 넣으면 노트북이 검사하고, 점수가 오를 때만 섞습니다.
  - `oof_<이름>.npy`: 6201×26 크기, train 순서
  - `test_<이름>.npy`: 2546×26 크기, test 순서
  - 열은 암 이름 **알파벳 순서**이고, 각 줄의 합은 1이어야 합니다.
- 나누는 방법이 다른 모델이라면 OOF로 비율을 고르지 말고, test 확률을 0.5 : 0.5 고정 비율로 섞습니다.

## 용어 사전

| 용어 | 뜻 |
|---|---|
| CV (교차검증) | train을 5조각으로 나눠 "4조각으로 공부 → 1조각으로 시험"을 5번 하는 연습 시험 |
| OOF | CV에서 각 환자가 "시험 조각"이었을 때 받은 예측. 연습 점수를 계산하는 데 씁니다 |
| LB (리더보드) | 실제 제출 점수. 이 대회는 test 전체로 채점합니다 |
| 데이터 누수 | 시험지를 미리 보고 공부한 것. 점수가 가짜로 높아지고, 이 대회에서는 수상 제외 |
| 피처 (재료) | 모델에게 주는 숫자들 |
| 사전학습 모델 | 다른 큰 데이터로 미리 공부를 마친 AI. 이 대회에서 사용 허용 |
| 변이 시그니처 | 암을 만든 원인이 DNA에 남긴 흔적의 모양 |
| 앙상블 (섞기) | 여러 모델의 답을 평균 내서 하나의 답을 만드는 것 |
