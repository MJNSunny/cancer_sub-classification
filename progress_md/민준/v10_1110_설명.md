# V10 쉽게 이해하기 (민준, 2026-11-10)

> 노트북: `v10_clean.ipynb` (원본 `v10_clean.py`) · 자세한 설계서: `docs/specs/2026-11-10-v10-clean-design.md`

## 한 줄 요약

**환자의 "유전자 고장 목록"을 보고 26가지 암 중 어떤 암인지 맞히는 모델**입니다.
기본 모델에 세 가지 아이디어를 더해서 연습 점수(CV)를 **0.42 → 0.50**으로 올렸습니다.
그런데 실제 제출 점수는 **0.417**이었습니다. 원인은 찾았고(아래 5번), 이제 고칠 차례입니다.

---

## 1. 무슨 문제를 푸나요?

- 환자 한 명 = 표의 한 줄입니다. 칸마다 유전자 이름이 있고, 고장(변이)이 없으면 `WT`, 있으면 `R175H` 같은 고장 표시가 적혀 있습니다.
  - `R175H` = "175번째 블록이 R에서 H로 바뀌었다"는 뜻입니다.
- 이 고장 목록만 보고 **어떤 암인지(26종)** 맞힙니다.
- 점수(**Macro F1**)는 26개 암을 **과목별로 채점해서 평균**낸 것입니다. 환자가 적은 암도 많은 암과 똑같이 중요합니다.

## 2. 절대 지키는 규칙: "시험지 미리 보기 금지"

대회 규칙상 **test(시험지)를 학습에 쓰면 실격**입니다. 그래서:

- 어떤 유전자를 볼지, 숫자를 어떻게 맞출지 등은 **train(연습문제)만 보고** 정합니다.
- test 환자는 **한 명씩 따로** 처리합니다. 다른 test 환자 정보를 같이 보지 않습니다.
- 노트북 7번 절에서 이 규칙을 지켰는지 **자동으로 검사**합니다. 통과하지 못하면 노트북이 멈춥니다.

## 3. 모델은 어떻게 생겼나요?

두 모델이 각자 답을 내고, **반반 섞어서** 최종 답을 정합니다.

| 모델 | 비유 | 잘하는 것 |
|---|---|---|
| **LightGBM** | 스무고개 ("TP53이 고장났나? → 예 → APC도?") | 여러 고장이 함께 있는 패턴 |
| **로지스틱 회귀** | 점수표 (고장마다 암별 점수를 더함) | 고장 하나하나의 영향, 많은 정보를 고르게 반영 |

### 모델에 주는 재료

**① 기본 재료**: 어떤 유전자가 고장났나 / 유전자가 아예 끊어졌나 / 정확히 어느 위치가 고장났나 / 고장이 모두 몇 개인가

**② Geneformer: 미리 공부한 AI의 "유전자 성격표"** (CV +0.020)
- Geneformer는 세포 1억 개 이상을 미리 공부한 AI 모델입니다. 대회 규칙상 **사전학습 모델은 사용 가능**합니다.
- 이 모델은 유전자마다 "어느 조직에서, 어떤 유전자와 함께 일하는지"를 숫자 768개로 정리한 **성격표**를 갖고 있습니다.
- 환자의 고장난 유전자들의 성격표를 평균 내서 재료로 씁니다. 예를 들어 "고장난 유전자들이 주로 피부 쪽 유전자다" 같은 힌트를 얻습니다.
- 이 재료는 **로지스틱 회귀에만** 줍니다. 둘 다 줬더니 LightGBM이 숫자 768개에 정신이 팔려 오히려 나빠졌습니다.

**③ 변이 시그니처: 범인이 남긴 지문** (CV +0.052, 가장 큰 효과)
- 암을 만든 원인마다 DNA에 남기는 **흔적 모양이 다릅니다**.
  - ☀️ 자외선(피부암 SKCM): C가 T로 바뀌는 흔적
  - 🚬 담배(폐암 LUSC·LUAD): C가 A로 바뀌는 흔적
- 데이터에는 DNA 대신 단백질 변화(`R175H`)만 있습니다. 그래서 생물 시간에 배우는 **유전 암호표**(DNA 3글자 → 아미노산 1개)를 거꾸로 써서 "이 변화를 만든 DNA 흔적"을 추정했습니다.
- 환자마다 흔적 6종류의 비율을 재료로 씁니다.
- 결과: 폐암(LUSC) +0.21, 간암(LIHC) +0.15, 자궁경부암(CESC) +0.13. 실제 생물학과 맞게 올랐습니다.

**④ 쌍둥이 규칙: 같은 사람이 이름표 두 개** (시뮬레이션 +0.043)
- 이 데이터의 암 이름 중 **KIPAN은 "신장암 전체 모음"**이라서 KIRC(신장암의 한 종류) 환자가 **KIPAN으로도 한 번 더** 들어 있습니다. **GBMLGG(뇌종양 모음)와 LGG**도 마찬가지입니다.
- 그래서 고장 목록이 **글자 하나까지 똑같은 두 사람**이 있습니다. train에서 신장 270쌍, 뇌 173쌍을 찾았습니다.
- 규칙: test 환자의 고장 목록이 train의 KIRC 환자와 똑같으면, 그 사람의 다른 이름표인 **KIPAN**으로 답합니다. 반대 방향과 뇌종양 쌍도 마찬가지입니다.
- test 222명(8.7%)에 적용됩니다. 연습에서는 99.7%가 맞았습니다.
- 규칙 위반이 아닌 이유: train으로 만든 명단에서 test 환자 **한 명씩** 찾아볼 뿐, test끼리는 비교하지 않습니다.
  - 팀이 찜찜하면 `USE_TWIN=0`으로 끌 수 있습니다.

## 4. 점수 기록

| 실험 | 바꾼 것 | 연습 점수 (CV) | 제출 점수 (LB) |
|---|---|---|---|
| baseline | 기본 재료만 | 0.424 | – |
| gf_lr | + Geneformer 작은 버전 | 0.434 | – |
| gf2_lr | Geneformer 큰 버전으로 교체 | 0.444 | – |
| **gf2_sig** | + 변이 시그니처 + 쌍둥이 규칙 | **0.496** | **0.417** |

- 새 아이디어는 연습 점수가 **+0.003 이상** 오르고, 5번 나눠 본 시험 중 **3번 이상** 올라야 채택했습니다. 운으로 오른 것을 걸러내기 위해서입니다.

## 5. ⚠️ 왜 제출 점수가 낮았나요? (가장 중요)

**test의 약 1/3이 train과 다른 "양식"으로 적혀 있었습니다.** 같은 내용을 다른 글씨체로 쓴 시험지라고 생각하면 됩니다.

| | train (연습문제) | test 중 879명 (35%) |
|---|---|---|
| 단백질 끝(종결) 표시 | `R1450*` | `R1450X` |
| 한 칸에 적힌 고장 수 | 평균 1.2개 | 평균 1.9개 (같은 고장을 여러 버전으로 반복해서 적음) |
| 환자당 고장난 유전자 수 (중간값) | 23개 | 53개 |
| `del`, `ins` 표시 | 없음 | 있음 |

- 모델은 "고장이 아주 많은 환자 = 위암·대장암(STES·COAD)"이라고 배웠습니다.
- 그래서 이 879명 중 **61%를 위암(STES)으로** 찍었습니다. 연습 점수는 높은데 제출 점수가 낮은 이유입니다.

## 7. 팀원이 할 일

### 노트북 실행하기
1. `pretrained/geneformer_v2/`에 Hugging Face `ctheodoris/Geneformer`의 파일 4개를 받습니다. 약 420MB입니다.
   - `Geneformer-V2-104M/model.safetensors`
   - `Geneformer-V2-104M/config.json`
   - `geneformer/token_dictionary_gc104M.pkl`
   - `geneformer/gene_name_id_dict_gc104M.pkl`
2. `train.csv`, `test.csv`, `sample_submission.csv`, `folds.csv`를 같은 폴더에 둡니다.
3. 실행합니다(약 5분). 결과는 `out/<실험명>/`에 저장됩니다.
   - 설정은 환경변수로 바꿀 수 있습니다. 예: `$env:EXP="test1"; $env:HGVS_LEGACY="1"; python v10_clean.py`
   - Geneformer 파일 없이 돌리려면 `USE_GF=0`으로 끕니다.

  - 열은 암 이름 **알파벳 순서**, 각 줄의 합은 1이어야 합니다.
- 노트북이 파일을 검사하고, 섞어서 점수가 오를 때만 섞습니다.

## 용어 사전

| 용어 | 뜻 |
|---|---|
| CV (교차검증) | train을 5조각으로 나눠 "4조각으로 공부 → 1조각으로 시험"을 5번 하는 연습 시험 |
| LB (리더보드) | 실제 제출 점수 |
| 데이터 누수 | 시험지를 미리 보고 공부한 것. 점수가 가짜로 높아지고, 대회에서는 실격 |
| 피처 | 모델에게 주는 재료(숫자) |
| 사전학습 모델 | 다른 큰 데이터로 미리 공부를 마친 AI. 대회에서 사용 허용 |
| 변이 시그니처 | 암을 만든 원인이 DNA에 남긴 흔적의 모양 |
